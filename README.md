# DataStructures and Algorithms
This repo contains data structures and algorithms exercises in Java and Python languages.

# Project Structure
Files are organized by topics with implementation code in java and python stored under the same folder.

Example: Folder structure for Linear Search algorithm:
    
    DataStructures/
    ├── Algorithms/
    │   ├── SearchingAlgorithms/
    │   │   └── LinearSearch/
    │   │       ├── linear_search.py
    │   │       └── LinearSearch.java

# How to run the program?

For Java : 
 1. Open the terminal in the project root.

 2. Compile the java source code
    javac <ClassPath>ClassName.java

    Example :
     DataStructures$ javac SearchingAlgorithms/LinearSearch/LinearSearch.java
     '''OR'''
     LinearSearch$ javac LinearSearch.java
    
 3. Execute the compiled .class file
    java <ClassPath> ClassName

    Example:
     DataStructures$ java -cp SearchingAlgorithms/LinearSearch LinearSearch
     '''OR'''
     LinearSearch$ java LinearSearch

For Python :
 1. Open terminal in the project root.

 2. Execute the python file
    python <FilePath>python_program.py

    Example:
     SearchingAlgorithms$ /usr/bin/python DataStructures/Algorithms/SearchingAlgorithms/LinearSearch/linear_search.py
     '''OR'''
     SearchingAlgorithms$ python LinearSearch/linear_search.py

| Character | Unicode | Input                         |
| --------- | ------- | ----------------------------- |
| `─`       | U+2500  | `Ctrl+Shift+U`, `2500`, Enter |
| `│`       | U+2502  | `Ctrl+Shift+U`, `2502`, Enter |
| `├`       | U+251C  | `Ctrl+Shift+U`, `251c`, Enter |
| `└`       | U+2514  | `Ctrl+Shift+U`, `2514`, Enter |


├── -> Indicates more items after this.
└── -> Indicates last item at this level.
